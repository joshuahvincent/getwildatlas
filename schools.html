Questions

The quick answers.

Does it cost us anything?

No, it’s free right now.

What is a Wild Atlas pack?

A pack is a set of animals in the Wild Atlas app. Your class pack holds the 18 animals your class picked. Each animal has a picture, facts read aloud, and a map of where it lives, and there are quizzes to play. It’s free for your class and families.

What student information do you collect?

None. We never ask for student names or accounts. The vote is a tick sheet, and the only thing we need back is your class’s final list of 18 animals.

Can children vote if they can’t read yet?

Yes. Each animal is a picture with its name. A grown-up reads the names aloud and children tick the pictures.

What if the class picks an animal you don’t have?

The pack uses animals that are in Wild Atlas. If a favorite isn’t there yet, we’ll tell you and suggest the next most-picked animal.

How do families get the pack?

Each class gets a code to share. Families redeem it in one tap from a link, or in the app’s “Redeem a Code” sheet.

Which grades is this for?

Pre-K through first grade. The vote is pictures and tick boxes, so the whole class can take part with a grown-up’s help.
